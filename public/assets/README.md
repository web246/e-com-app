Place logo and icon assets here for production builds.

- `app-icon-192.png` - 192x192 app icon used in manifest
- `app-icon-512.png` - 512x512 app icon used in manifest
- `favicon.ico` - browser favicon
- `logo-light.png` - primary logo with light background
- `logo-dark.png` - primary logo with dark background

Guidelines:
- Provide PNGs with transparency as needed.
- For best results, export logo at exact pixel sizes and use square canvases for icons.
